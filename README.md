# CityOps Property UI — Enhanced Prototype

A polished React + TypeScript + Tailwind property-management UI based on the supplied CityOps screens.

## Included screens
- Dashboard / portfolio overview
- Investors & Owners
- Contract Agreements
- Agreement Template editor with clickable placeholder tags
- Manage Buildings
- Building create/edit form with Building + Floor Plan tabs
- Investor Relation
- Tenants & Rentals
- Building Rents
- Building Expense
- Credit / Debit Sources with edit modal
- Bank Details
- Financial
- Available Buildings
- Building Total Cost
- Owner's Buildings
- Investor's Investment

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

This is a front-end prototype with local mock data and interactions. It is intentionally separated from the existing backend/API so the UI can be reviewed safely before integration.
